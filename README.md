10. Visual Design

The overall design must be:

Dark + Minimal + Professional + Modern + Developer-focused

Color palette

Use a sophisticated dark background, preferably:

 Near-black / charcoal primary background

 Slightly lighter dark cards

 White/off-white typography

 One subtle accent color for buttons, links, highlights, and interactive elements

Avoid excessive neon colors.

The design should feel similar to a modern developer/product designer portfolio rather than a generic template.

Typography

Use a modern sans-serif font such as:

 Inter

 Geist

 Manrope

 Plus Jakarta Sans

Use strong typography hierarchy:

 Large bold hero heading

 Medium section headings

 Clean readable body text

 Small uppercase labels for categories
